# Sovereign Claw local finalization rules

This repository is developed in coherent, local-first batches. Do not create
workflows that write to source branches, weaken authority boundaries, or turn
unknown/unverified state into success.

Closure authority is exclusively derived from server-owned validation,
immutable execution authority, independently measured state, and verified
ProofVault membership. Callers, agents, compatibility APIs, and scalar values
must never mint authoritative closure.

Before publication, run the targeted and full local gates, perform an
independent security/correctness review, reconcile the remote head, and publish
one completed engineering state.
